# SFML spaceship Shooting Game🔫

### FIRST MAKE SURE YOU INSTALL THE SFML LIBRARY LOCALLY AND CHANGE THE PATHS IN THE MAKEFILE FOR THE LIB FOLDER and INCLUDE FOLDER

### COPY THE IMPORTANT DLL FILES TO THE ROOT FOLDER OF THE PROJECT

HOW TO RUN THE GAME?

## How to compile to the code?:

```bash
make
```

This will execute the command mentioned in the Makefile. The game will be compiled and an executable file will be created.

## Run the game by executing the following command:

```bash
make run
```

This will execute the command mentioned in the Makefile under run section. The game will be launched in a window.
OR you could just simply run the executable file created in the previous step.

## If you want the cleanup:

```bash
make clean
```

This will execute the command mentioned in the Makefile under clean section. The game will be cleaned up and all the object files will be deleted.
